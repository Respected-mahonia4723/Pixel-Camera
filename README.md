## 🆘 Troubleshooting

### App won't open
- Make sure you've extracted the ZIP file completely (if you downloaded a ZIP)
- Right-click the app and select "Run as administrator"
- Check that your antivirus isn't blocking the app

### Phone not detected
- Use a different USB cable (some cables only charge)
- Enable USB debugging: Go to Settings → About Phone → Tap "Build Number" 7 times → Go back to Settings → Developer Options → Turn on "USB Debugging"
- Try a different USB port on your computer

### Features not appearing on phone
- Restart your phone after installation
- Make sure your phone is on Android 14 or newer
- Check that your phone model is in the supported list above
